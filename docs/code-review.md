# Code Review Notes

## 현재 구조

- `app/`: Next App Router 페이지와 API Route.
- `components/`: 페이지 간 공유 UI 컴포넌트.
- `lib/`: 도메인 로직, 타입, SWR 훅, 검증, JSON store.
- `data/`: 앱에 번들되는 정적 JSON.
- `data/user/`: 런타임 사용자 JSON 저장소이며 git 추적 대상이 아님.

## 현재 기능

- 대시보드: 날씨, 환율, 예산 잔액, 체크리스트, 택배, 휴일, 콘서트 마일스톤 요약.
- 가계부: 예산 템플릿, Google Sheets 월별 집계, 카테고리별/월별 차트, 목표저축.
- 일본 생활: 출국/정착 체크리스트, 쓰레기 배출일, 택배 트래킹 링크.
- 음악/J-Pop: 아티스트 검색, 즐겨찾기, 최신 릴리즈, Top 100, 콘서트 관리, 티켓 일정.
- 학습: 일본어 노트, SRS 퀴즈 상태, 노래방 검색.
- 계산기: 일본 급여/공제 추정, 실시간 환율 기반 변환.

## 정리한 레거시/덤프

- Notion export 원본(`notion/`)은 앱에서 사용하지 않아 제거.
- Claude 로컬 권한 파일(`.claude/`)은 개인 환경 파일이라 제거.
- Finder/TypeScript/Next 생성물(`.DS_Store`, `tsconfig.tsbuildinfo`) 제거.
- 런타임 사용자 데이터 샘플(`data/user/checklist.json`, backups)은 정적 기본값과 중복되어 제거.
- `.gitignore`에 `.claude/`, `notion/`을 추가해 재유입 방지.

## 리팩토링

- Sheets 집계 로직을 `lib/sheets.ts`로 분리.
- `/api/sheets`와 `/api/sheets/trend`가 같은 파서/집계 함수를 공유하도록 변경.
- Docker standalone 이미지에 필요한 정적 JSON 복사를 명시적으로 보강.
- 예산 store 버전을 `v5`로 문서와 코드에서 일치시킴.

## 남은 개선 후보

- API CRUD Route의 `safeSave`, id 생성, 에러 응답 패턴을 공통 helper로 통합.
- Google Sheets API key, sheet id, range를 환경변수화해 개인 시트 교체 비용 낮추기.
- `data/user` 백업은 현재 파일 저장 시 생성되므로 보관 정책/복원 UI를 추가하면 안정성이 좋아짐.
- 빌드 산출물과 개인 런타임 데이터가 커지므로 정기 cleanup script를 `package.json`에 추가 가능.

## 일본 생활 3개월차 추천 기능

- 주민세/사회보험 캘린더: 첫 월급 이후 공제 변동, 주민세 시작 시점, 연말정산 준비 알림.
- 정기 지출 탐지: Sheets 기반 구독/월세/통신비 자동 감지와 미입력 경고.
- 관공서/생활 업무 리마인더: 마이넘버, 재류카드 주소, 은행/신용카드, 건강보험, 후루사토 납세 체크.
- 병원/약/보험 메모: 진료 기록, 약 이름, 보험증/마이넘버 사용 여부, 다음 예약일.
- 교통비/정기권 관리: 통근 정기권 기간, 교통비 청구, IC 충전 추적.
- 재난/날씨 준비: 태풍·폭염·지진 대비 체크리스트, 비상 연락처, 비축품 점검.
- 생활 장소 북마크: 슈퍼, 드러그스토어, 병원, 구청, 우체국, 세탁소를 지도 링크로 관리.
- 일본어 실전 로그: 회사/관공서/병원에서 실제로 막힌 표현을 노트와 SRS로 바로 연결.
